# Capture Studio

截取、标注，然后直接粘贴的 Mac 应用。

[한국어](README.ko.md) · [English](README.en.md) · [日本語](README.ja.md) · [简体中文](README.zh-Hans.md)

## 主要功能

- 区域、窗口和全屏截图，可自定义全局快捷键
- 登录时在菜单栏中自动启动
- 无需显示 Dock 图标即可截图并自动复制，点击缩略图即可编辑
- 箭头、矩形、文字、遮挡和裁剪
- 编辑后自动复制，支持撤销和重做
- 打开、拖入或粘贴图片，导出 PNG
- 保留最近的图片和编辑内容，可更改存储文件夹
- 仅在启用后自动清理旧项目
- 简体中文、韩语、英语、日语及更新检查
