# 호환성

macOS 14 이상에서 사용하는 Intel·Apple Silicon 통합 앱입니다.

- macOS 15.7.4 / Apple Silicon에서 실제 화면과 캡처·편집·보관 흐름을 점검했습니다.
- CI는 macOS 14, macOS 15, macOS 15 Intel에서 자동 검사를 실행합니다. CI 결과와 실제 사용자 환경의 검증 범위는 다릅니다.
- 화면 캡처에는 화면 기록 권한이 필요합니다. 이미지 파일만 편집할 때는 필요하지 않습니다.
- 이 배포본은 Apple 공증을 받지 않았습니다. macOS가 처음 실행을 제한할 수 있습니다.
- 임시 코드 서명으로 인해 앱을 교체한 후 화면 기록 권한을 다시 등록해야 할 수 있습니다.

설치 직후의 권한 요청, 실제 재로그인 시 자동 실행, 물리 키보드의 전역 단축키, 여러 모니터와 다른 macOS 버전의 전체 사용 흐름은 추가 검증이 필요합니다.
