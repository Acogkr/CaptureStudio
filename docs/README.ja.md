# Capture Studio

撮って、書き込んで、そのまま貼り付けられるMacアプリです。

[한국어](README.ko.md) · [English](README.en.md) · [日本語](README.ja.md) · [简体中文](README.zh-Hans.md)

## 主な機能

- 領域・ウインドウ・画面全体のキャプチャとグローバルショートカット設定
- 撮影後に自動コピー、サムネイルをクリックして編集
- 矢印・四角形・テキスト・目隠し・切り抜き
- 編集内容の自動コピーと取り消し・やり直し
- 画像を開く・ドラッグ・貼り付け、PNGで保存
- 最近の画像と編集内容を保存、保存先の変更
- 有効にした場合のみ古い項目を自動整理
- 日本語・韓国語・英語・簡体字中国語と更新確認
