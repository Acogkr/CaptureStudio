# Capture Studio

캡처하고, 표시하고, 바로 붙여넣는 Mac 앱입니다.

[한국어](README.ko.md) · [English](README.en.md) · [日本語](README.ja.md) · [简体中文](README.zh-Hans.md)

## 주요 기능

- 영역·창·전체 화면 캡처와 전역 단축키 설정
- 캡처 즉시 자동 복사, 썸네일을 클릭하면 편집
- 화살표·사각형·텍스트·블라인드·자르기
- 편집 내용 자동 복사와 실행 취소·다시 실행
- 이미지 열기·끌어오기·붙여넣기와 PNG 저장
- 최근 이미지와 편집 내용 보관, 보관 폴더 변경
- 선택한 경우에만 오래된 항목 자동 정리
- 한국어·영어·일본어·중국어 간체와 새 버전 확인
